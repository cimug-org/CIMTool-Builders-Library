# CIMTool Builders Library logo

The CIMTool Builders Library logo is the CIM Users Group disc set inside a cog: the disc stands for the CIM profile, and the cog for the builders that turn it into schemas, code and documentation.

| File | Use |
|---|---|
| `cimtool-builders-logo.svg`, `cimtool-builders-logo-1200.png` | Logo and wordmark, for light backgrounds |
| `cimtool-builders-logo-dark.svg`, `cimtool-builders-logo-dark-1200.png` | Logo and wordmark, for dark backgrounds (the website header) |
| `cimtool-builders-mark.svg`, `cimtool-builders-mark-<size>.png` | The mark alone, for light backgrounds and icons (16 to 512 px) |
| `cimtool-builders-mark-dark.svg`, `cimtool-builders-mark-dark-512.png` | The mark alone, for dark backgrounds |
| `favicon.ico` | Browser icon (16, 32 and 48 px); a copy is at the repository root for the website |
| `cimtool-builders-social-1280x640.png` | GitHub social preview (Settings › Social preview) |

The wordmark is set in [Montserrat](https://github.com/JulietaUla/Montserrat) (SemiBold for "CIM" and "LIBRARY", Regular for "Tool Builders") and converted to outlines, so the SVGs need no fonts. Montserrat is licensed under the SIL Open Font License; see `Montserrat-OFL.txt`.

Colours are from the CIM Model Management brand palette: the disc keeps the CIMug gradients; the cog is navy `#0A2E57` (`#C9D6E3` on dark backgrounds); the wordmark is `#231F20` with "CIM" in brand blue `#0058A9` and "LIBRARY" in brand teal `#0097A5` (white and light teal `#7FD3DC` on dark backgrounds).
